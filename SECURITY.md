# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older extension ZIPs
may not receive backports.

## Report a vulnerability

Please use GitHub's **Security** tab and choose **Report a vulnerability** so details remain
private. If private vulnerability reporting is not available, open a public issue requesting
a private contact channel, but do not include vulnerability details.

Include, where possible:

- the affected version or commit;
- the browser and operating system;
- a minimal reproduction that contains no book text, credentials or private Notion data;
- the expected impact;
- any suggested mitigation.

Do not test against accounts, databases or content you do not own or have permission to use.
Please allow reasonable time for triage and a fix before public disclosure.

## Secrets and private data

Never submit API keys, Notion integration tokens, authorization headers, full database IDs,
copyrighted book passages or personal notes. Revoke exposed credentials immediately and
remove sensitive values from screenshots and logs.
